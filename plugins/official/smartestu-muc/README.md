# 数你最灵

可选网页跟踪插件 0.1.2，需要自动登录修复版行程（插件接口第 3 版）。

在插件窗口展开“自动登录”，填写学校的完整名称、账号和密码，点击“保存并启用”。学校名称与网站的选项保持一致；下次登录会恢复该学校，再填写凭据。学校不限于某一所，找不到学校时停止自动登录，不会随便选择其他学校或提交密码。验证码和扫码仍需手动完成。

账号密码由行程按当前 Windows 用户和插件隔离加密保存在本机，学校保存在本机插件设置中。请勿把账号密码写进插件文件。新会话不会预设学校，旧用户首次升级需要填写学校并保存。

读取个人页面中的学校与学号，再读取全部班级、全部状态的作业列表；不同学校的同一学号互相隔离。原先已适配账号的来源编号保持一致。仅同步任务与完成状态，不提交作业、签到、参加考试或修改成绩。

页面未公开独立作业编号，使用账号、班级、名称和发布时间组合关联；重复组合会停止同步，改名或修改发布时间可能形成新来源。已完成任务只更新既有来源待办，未完成任务可新建待办。其他学校页面结构如不同，需要进一步适配，不保证所有学校均已实测。

入口为 https://smartestu.cn/login 。所需文件为 `plugin.json`、`read.js`、`auto-login.js`，无需额外脚本运行环境。插件编号继续保留原值，避免升级后重复导入待办。
