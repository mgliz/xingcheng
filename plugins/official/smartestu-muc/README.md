# 数你最灵 · 中央民族大学

行程项目维护的可选网页跟踪插件。版本 0.1.0，测试适配，需要行程插件接口第 2 版（rc.5 新版）。软件安装包不包含本插件。

安装后打开连接，插件在登录页面预选中央民族大学；请使用自己的账号密码登录。先读取预览，确认作业字段后再开启同步。仅读取个人页面中的账户标识和作业列表，不提交作业、不参加考试、不签到、不修改成绩。

读取账户页面后加载“全部班级、全部状态”的作业列表，提取标题、班级、截止时间和完成状态；列表必须明确加载完整，部分加载或过滤结果不会合并。

页面没有公开独立的作业编号，因此使用账户、班级、作业名称与发布时间组合关联。遇到同一组合的重复记录会停止同步；平台改名或修改发布时间可能形成新的来源，不按同名任务猜测关联。任务链接打开作业列表，列表中的详情由平台按钮进入。

已完成任务只更新已有来源待办；未完成任务可新建待办。账号标识仅参与来源散列，不写进插件包；插件也不保存密码、验证码或令牌。自动同步使用行程的独立浏览器登录状态。

入口：https://smartestu.cn/login 。适配文件为 `plugin.json`、`read.js` 与 `login.js`，无需 Node.js 或额外脚本环境。`login.js` 只预选学校，不填写账号密码。其他学校请自行修改并使用新的插件编号，避免被官方更新覆盖。
