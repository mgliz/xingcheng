# 学习通

行程项目维护的可选网页跟踪插件。支持在插件窗口加密保存登录信息和可选自动登录。版本 0.1.1，测试适配，需要行程插件接口第 3 版（自动登录修复版）。软件安装包不包含本插件。

从官方插件市场安装后，在“网页跟踪”打开学习通，在网页中登录。先读取预览，确认作业字段后再开启自动同步。支持“我的作业”汇总页分页、未提交／退回／提交状态、完整日期与剩余时间截止描述。

已提交或完成的作业会完成已有来源待办；不会为历史已完成作业批量新建待办。已删除并忽略的来源不会重新导入，本地标题、备注与排程保留。

来源编号兼容旧版学习通导入；安装插件时沿用旧连接的自定义名称，原有待办可以继续关联。旧连接不会自动启用或自动安装。旧登录资料保留，本插件的独立浏览器可能需要重新登录。

适配文件为 `plugin.json` 和 `read.js`；账号、密码与 Cookie 均不放入插件。网站结构变化时单独更新本插件，不需要重新发布软件。平台页面未识别时停止合并，不将解析失败视为没有作业。
