# 插件市场

网页跟踪插件按需安装、独立更新。行程软件不再自带学习通插件；没有安装插件时不会启动学习通连接。

## 官方插件

由行程项目维护。目前为测试适配，安装需要支持插件接口第 2 版的 rc.5 新版。

| 插件 | 版本 | 说明 | 下载 |
| --- | --- | --- | --- |
| [学习通](official/chaoxing/README.md) | 0.1.0 | 作业读取、分页、完成状态同步 | [插件包](packages/chaoxing-0.1.0.zip) |
| [数你最灵（中央民族大学）](official/smartestu-muc/README.md) | 0.1.0 | 账户隔离、作业状态与截止时间读取 | [插件包](packages/smartestu-muc-0.1.0.zip) |

GitHub 与 AtomGit 提供相同的插件包和市场索引。行程内的“网页跟踪 → 官方插件市场”可安装并检查更新，GitHub 无法访问时使用 AtomGit 镜像。插件版本与软件版本分别维护，不依赖软件更新来修复网站适配。

也可以下载插件包，在本机解压后，通过行程的“导入插件”选择其中的 `plugin.json`。包中含所需配置与脚本，不需要另装 Node.js、Python 或其他脚本运行环境。网页登录由行程提供，使用者在网站内登录自己的账号。

## 自定义适配

每个插件由 `plugin.json` 和同目录脚本组成。源代码在 `official/<插件编号>/<版本>/`，可以自行调整。自定义修改请更换插件编号，避免与官方插件混用；同编号的手动导入插件不会被市场更新覆盖。

插件脚本在声明网站的登录页面和任务页面运行，请先阅读源码及域名范围。密码、验证码、Cookie 和访问令牌不应写入配置、源码、任务链接或调试结果。所有课表与待办写入仍经过行程的版本校验和正常保存事务。

## 插件维护

每次适配更新增加独立插件版本，新增版本目录和对应 ZIP 包，更新 `marketplace.json` 中的版本、大小和 SHA-256。旧版本包保留，避免运行中的下载被覆盖。先更新插件文件和包，最后更新市场索引；两平台对应文件必须一致。

软件安装与卸载插件时保留待办。更新失败或校验不一致时保留原插件；旧版本文件在本机 `.rollback` 目录留备份，卸载文件在 `.removed` 目录留备份。不会把用户登录资料打进发布包。
